# T37 — путь псевдо-C → C → ZDL

## Что сделано

- Добавлен `cfw\s3k\emit_c.py`: он берёт аудиофункцию ZDL и выдаёт компилируемый C.
  Регистры C674x представлены union `reg_t { unsigned int u; float f; }`,
  доступ к памяти идёт через макрос `MEM32(base, off)`.
- Для проверки выбран стоковый parametric EQ `ST GT GEQ`.
  Сгенерированный файл: `cfw\s3k\rebuild\st_gt_geq\st_gt_geq.c`.
- Добавлены манифест и `build.py`, которые компилируют C через TI `cl6x`
  и собирают ZDL через `toolchain\zdl\linker.py`.
- Результат: `C:\zoom\zdlnew\ST_GT_GEQ_REBUILT.ZDL`, 8538 байт.
  Линкер: `.audio` 768 B, `.fardata` 0 B, relocations 0, внешних символов нет.

## Важные исправления по пути

- Результаты float-операций должны писаться в `.f` поля union: запись в `.u` вызывала
  float→int преобразование и внешний символ `__c6xabi_fixfu`.
- В сгенерированный C добавлен `#pragma CODE_SECTION(..., ".audio")`, иначе
  линкер не находил секцию `.audio`.

## Проверка звука

`c6xzdl` с `--func Fx_ST_GT_GEQ --fw-stubs`:

- rebuilt: RMS `0.19843`, 264592 float-сэмплов, звук есть;
- original ZDL в этом же запуске дал нулевой `out.f32` — известное ограничение
  автономного стенда для стоковых эффектов, а не доказательство поломки звука.
  Побайтовое сравнение original ↔ rebuilt в `c6xzdl` поэтому невозможно.

Размер 8538 байт укладывается в предел ZDL около 32 КБ.

## Границы

- Эмиттер пока покрывает набор команд выбранного эффекта: LDW, LDNDW, STW,
  MV, MVK, MVKH, ADD, ADDK, SHL, MPYSP, ADDSP, SUBSP, CMPLTSP, CMPGTSP,
  B, BNOP, NOP. Для других эффектов нужно расширять шаблоны.
- Это компилируемый эквивалент machine-кода, а не восстановленный исходник:
  имена переменных и типы остаются синтетическими.
- Для эффектов-заглушек нужно сначала поднять движок из прошивки (T36).
